# Reading Clinic · Writing Clinic

화전 우등생 학원 영어 연습장입니다. 메인은 **Reading Clinic**(독해 기초), 보조는 **Writing Clinic**(글쓰기 첨삭)입니다.

## 주소

| 주소 | 화면 | 파일 |
|---|---|---|
| `/` | 허브: 연습 고르기, 얻을 수 있는 것, 저장 안내 | `index.html` |
| `/reading` | 수식어 찾기 | `drill.html`, `drill-data.js` |
| `/reading/core` | 문장성분 찾기 | `core.html`, `core-data.js` |

| `/stats` | Writing 통계 | `stats.html` |

Reading 공통: `reading.css`(디자인), `learn.js`(기록·학습 코드·숙련도·모의고사 연결), `exam-map.js`(모의고사 연결 데이터).

## Reading Clinic

- 학년: 예비 고1 · 고1 · 고2 · 고3. 문장 수 10/20/30. 랭킹과 제한 시간은 없음(풀이 시간은 기록).
- 틀리면 이유와 "생각해 볼 점"을 먼저 보여 주고, 한 번 더 도전한 뒤 정답을 보여 줌. 힌트 2단계.
- 고르는 방법: 드래그 / 두 번 톡(시작 → 끝). 터치 화면이면 처음엔 두 번 톡.
- 패턴(형식)마다 **첫 시도** 결과가 쌓이고, 기준(분석 기준 탭)에 따라 측정 중 / 연습 중 / 익힘으로 표시. 약한 패턴만 모아 복습.
- 학습 코드(닉네임 + 숫자 4자리): 실명·연락처 없이 다른 기기에서도 기록이 이어짐.
- 모의고사 연결: `exam-map.js`에 실제 모의고사 문장의 패턴 표시 데이터가 있을 때만 "모의고사 문장 100개 중 약 N개" 문구가 나옴. 만드는 방법은 `tools/exam-tagging.md`.

## Writing Clinic

- 기존 첨삭 그대로(하루 3회, 같은 글 = 같은 결과).
- 실시간 도우미: 글을 쓰다 n초 멈추면 말을 검. 문장을 끝내고 멈추면 "방금 쓴 문장 점검받기"(고친 문장이 아니라 어디를 볼지 힌트 하나), 문장 중간에 멈추면 막혔을 때의 방법 안내. n은 레벨별로 분석 기준 탭에서 정하고, 학생 반응(괜찮아요·무시·점검받기)에 따라 기기마다 조금씩 조정. 첨삭 3회와 따로 셈.

## 구글 시트 (Apps Script v10)

탭: 첨삭 기록 · 저장된 결과 · **Reading 기록**(한 줄 = 한 판, 문장별 결과는 상세 JSON) · **학습자** · **어시스턴트 기록** · **분석 기준** · **결정 기록** · **주간 브리핑**. 예전 `드릴 기록`(랭킹) 탭은 지우지 않고 누적 횟수에만 더해 셉니다.

1. `tools/apps-script.gs` 전체를 Apps Script 편집기에 붙여 넣고 `SECRET`을 기존 값으로.
2. **배포 → 배포 관리 → 연필(편집) → 버전: 새 버전 → 배포.** ("새 배포"를 하면 주소가 바뀌어 `LOG_URL`을 다시 넣어야 함)
3. 프로젝트 설정에서 시간대를 서울(GMT+9)로, 편집기에서 `setupAutomation`을 한 번 실행(메일 권한 허용) → 매주 토요일 9시 브리핑, 매일 21시 점검.
4. (선택) 스크립트 속성에 `ANTHROPIC_API_KEY`를 넣으면 브리핑 맨 위에 AI 요약이 붙음. 숫자는 항상 코드가 계산.
5. 지금 바로 브리핑을 받아 보려면 `sendBriefingNow` 실행.

**분석 기준** 탭의 "값" 칸을 고치면 사이트(1분 안에)와 브리핑에 반영됩니다. 이번 주에 바꾸기로 한 것은 **결정 기록** 탭에 한 줄 적어 두면 다음 브리핑에 함께 나옵니다.
