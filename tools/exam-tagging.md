# 모의고사 연결 데이터 만들기 (`exam-map.js`)

학생 화면의 "이 패턴은 고2 모의고사 문장 100개 중 약 N개에 들어 있어요", "지금 익힌 것만으로 구조를 파악할 수 있는 고2 모의고사 문장: 약 N%"는 이 데이터로 계산합니다. 데이터가 없는 학년은 아무 숫자도 나오지 않습니다.

## 1. 문장 고르기

- 학년마다 실제 모의고사(학력평가) 독해 지문에서 문장을 모읍니다. 예비 고1은 고1 3월 또는 중3 수준.
- 숫자가 의미 있으려면 학년당 **200문장 이상**을 권합니다(최소 20문장이 있어야 화면에 나옴).
- 어느 시험에서 뽑았는지 `source`에 적어 두면 화면에 함께 표시됩니다.

## 2. 문장마다 표시하기

문장 하나에 두 가지를 표시합니다. 지문 원문은 파일에 넣지 않습니다.

- `f`: 주절의 형식 (1~5)
- `p`: 그 문장에 들어 있는 수식어 패턴 키 목록 (`drill-data.js`의 키: `A-S-rel`, `D-V-pp` 등)

```js
window.EXAM = {
  2: {
    source: '2025학년도 고2 3·6·9·11월 학력평가 독해',
    sents: [
      { f: 3, p: ['A-S-rel', 'D-V-pp'] },
      { f: 2, p: [] },
      { f: 5, p: ['A-O-ptc', 'D-SE-cl'] }
    ]
  }
};
```

표시는 Claude에게 지문을 주고 "tools/exam-tagging.md 형식으로 표시해 줘"라고 하면 초안을 만들 수 있습니다. 숫자가 학생에게 보이는 근거가 되므로, 초안은 선생님이 확인한 뒤 넣으세요.

## 3. 계산 방식

- 패턴 문구: 그 학년 문장 중 그 패턴이 들어 있는 문장의 비율.
- 구조 파악 비율: 학생이 '익힘'인 패턴만으로 문장의 모든 수식어 패턴이 설명되고(수식어 기준), 그 형식도 '익힘'인(형식 기준) 문장의 비율. 두 게임을 모두 했으면 둘 다 만족하는 비율을 보여 줍니다.
- 이 비율은 "이 문장들의 구조를 파악하는 데 필요한 패턴을 연습으로 익혔다"는 뜻이지, 어휘까지 포함해 해석할 수 있다는 보장은 아닙니다. 화면 문구도 이 범위로 씁니다.
